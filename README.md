## Sobre o projeto

A **Calculadora Web** é uma aplicação front-end criada para realizar operações matemáticas de forma rápida, simples e intuitiva.

O projeto começou como uma calculadora básica e foi evoluído para uma versão mais completa, com foco em:

- melhor experiência do usuário;
- interface mais moderna;
- interatividade mais rica;
- organização visual mais profissional;
- valor real para portfólio.

Nesta versão atualizada, a aplicação recebeu novas funcionalidades e um redesign visual para deixá-la mais forte como projeto acadêmico e profissional.

## Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar e demonstrar conceitos importantes do desenvolvimento front-end, incluindo:

- estruturação semântica com HTML;
- estilização moderna com CSS;
- manipulação do DOM com JavaScript;
- lógica de operações matemáticas;
- tratamento de erros;
- interação por clique e teclado;
- atualização dinâmica da interface;
- alternância de tema com persistência no navegador;
- organização visual mais profissional.

## Como executar localmente

1. Clone este repositório:
```
git clone https://github.com/phmbezerra/calculadora-web.git
```

2. Acesse a pasta do projeto:
```
cd calculadora-web
```

3. Abra o arquivo index.html no navegador.
